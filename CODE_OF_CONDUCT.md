# Code of Conduct

We want this project to be a welcoming, harassment-free space for everyone.

## Expected behaviour

- Be respectful and assume good faith.
- Give and accept constructive feedback.
- Focus on what is best for the project and the people using it.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Publishing other people's private information.
- Sustained disruption of discussions, issues or pull requests.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests, and may ban contributors who break these rules.

## Reporting

Report conduct problems privately to the maintainer at the address listed in the repository's About panel or profile. Security vulnerabilities go through the process in [SECURITY.md](SECURITY.md) instead.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
